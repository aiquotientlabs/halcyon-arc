Halcyon Arc / Platform
The Halcyon Arc Platform

One secure foundation, built cloud-native on AWS and Google Cloud.

Every Halcyon Arc solution runs on a shared platform for identity, encryption, model access, evaluation and audit. We design for Canadian data residency, least privilege and portability across both clouds.

Architecture principles

Why multi-cloud, and why cloud-native

  • Canadian residency. Production and health data are hosted in Canadian regions: AWS Canada (Central) and Canada West (Calgary); Google Cloud Montréal and Toronto.
  • Best model for the job. We evaluate and route between foundation models on Amazon Bedrock and Vertex AI, and use our own AI Safety suite to choose.
  • Managed and serverless first. Containers on Fargate and Cloud Run, functions for event workloads, managed databases. Less to patch, more to build.
  • Security as code. Infrastructure, policies and guardrails are versioned, reviewed and deployed through pipelines.
  • Portability. Containerized services and open standards (FHIR, OpenTelemetry, Terraform) keep us free to place each workload where it fits best.

Workloads

How each solution uses the cloud

Our products are compute- and model-intensive: evaluation campaigns, red-team generation, speech processing and model training all run on managed cloud services.

  • AI SafetyLarge-scale evaluation and red-team runs against foundation and fine-tuned models; scoring pipelines; result warehouse.
    AWS: Bedrock, SageMaker, Lambda, S3 · GCP: Vertex AI, Cloud Run, BigQuery
  • AI SecurityRuntime guardrail service screening prompts and responses; adversarial test generation; AI bill-of-materials store.
    AWS: Bedrock Guardrails, ECS Fargate, DynamoDB · GCP: Vertex AI, Cloud Run, Firestore
  • Cyber SecurityMulti-account posture collectors, log ingestion and AI-assisted triage of findings.
    AWS: Security Hub, Config, Lambda, OpenSearch · GCP: Security Command Center, Pub/Sub, BigQuery
  • Dementia DetectionSecure capture of speech tasks, transcription, feature extraction and model training on consented research data.
    AWS: Transcribe, SageMaker, S3, HealthLake · GCP: Speech-to-Text, Vertex AI, Healthcare API
  • Dementia CareVoice companion, routines engine, notifications and care-team portal.
    AWS: Bedrock, Lambda, SNS, RDS · GCP: Gemini on Vertex AI, Cloud Run, Cloud SQL

Security & privacy controls

How we protect data

  • Separate accounts and projects per environment and per sensitive workload, under organization-level guardrails
  • Encryption in transit and at rest with customer-managed keys; secrets never in code
  • Single sign-on with MFA for all staff; least-privilege, time-bound access to production
  • Centralized, immutable audit logs and continuous posture monitoring
  • Personal health information handled under PIPEDA and applicable provincial law, with consent records
  • Customer and participant data is never used to train general-purpose models without explicit consent
