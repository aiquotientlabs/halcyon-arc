Halcyon Arc for AI Security

Secure the new attack surface: your models, prompts and agents.

LLM applications and autonomous agents introduce threats traditional security tools miss. We find them, fix them and guard against them at runtime.

Book a discovery callSee how it works
The challenge

An AI agent with tools is a privileged user that takes instructions from strangers.

Prompt injection hidden in a web page, document or email can steer an agent into leaking data or taking unwanted actions. Retrieval pipelines can expose documents to the wrong users. Open-weight models and third-party plugins create supply-chain risk. These threats sit between application security and data security, and most teams own neither end.

Capabilities

Defence in depth for AI systems

AI penetration testing

Hands-on testing of LLM apps and agents for direct and indirect prompt injection, jailbreaks and data exfiltration paths.

AI threat modelling

Architecture reviews of RAG pipelines, tool calling and multi-agent systems using MITRE ATLAS techniques.

Agent permission design

Least-privilege tool scopes, human confirmation for sensitive actions and scoped credentials for every agent.

Runtime guardrails

An inspection layer that screens prompts and responses for injection, PII and policy violations before they reach users or tools.

Data protection for RAG

Document-level access control, tenant isolation and redaction so retrieval respects who is asking.

Model supply-chain assurance

Provenance checks for models, datasets and plugins, with an AI bill of materials for each release.

How it works

Test, harden, protect, repeat

Map

Inventory models, prompts, tools, data sources and trust boundaries across your AI estate.

Attack

Run a structured adversarial campaign and report exploitable paths with reproducible evidence.

Harden

Fix root causes: permission scopes, input isolation, output encoding, retrieval access control.

Guard

Deploy runtime screening and logging, and re-test automatically on each release.
